🔧 הגדרת Firebase — שלב אחת ויש לך אפליקציה אמיתית!

כרגע הנתונים נשמרים רק בדפדפן שלך. כדי שכל העובדים יראו את אותם נתונים בזמן אמת, צריך לחבר Firebase (חינמי לחלוטין).

1
פתח Firebase Console
כנס לכתובת: console.firebase.google.com עם חשבון Google שלך
2
צור פרויקט חדש
לחץ "Add project" ← שם הפרויקט: textileops ← המשך עד סיום הקמת הפרויקט
3
הפעל Firestore
בתפריט הצד ← Build ← Firestore Database ← Create database ← בחר "Start in test mode" ← בחר אזור ← Done
4
קבל את פרטי ה-Config
הגדרות פרויקט (⚙) ← General ← "Your apps" ← לחץ על כפתור Web (</>) ← שם: textileops ← Register app ← העתק את האובייקט firebaseConfig
5
הכנס את ה-Config כאן
הדבק את הערכים מ-Firebase:
6
פרוס ל-Netlify (30 שניות)
כנס ל netlify.com ← הירשם עם Google ← גרור את קובץ ה-HTML לאתר ← קבל כתובת URL ← שלח לכל העובדים!
